# MnemonicShards

一个安全、专业的助记词分片工具，使用 Shamir 秘密分享算法将您的助记词分割成多个分片，并提供可选的 OpenPGP 加密功能以增强安全性。任意指定数量的分片即可恢复原始助记词。

## 🚀 快速开始

### 构建静态文件（推荐）
```bash
git clone <repository-url>
cd MnemonicShards
npm install && npm run build
# dist/mnemonic-shards-offline.html 是自包含的单文件离线版，双击即可在任意浏览器中打开
open dist/mnemonic-shards-offline.html
```

### 本地开发
```bash
# 克隆并在本地运行
git clone <repository-url>
cd MnemonicShards
npm install && npm run dev
# 访问 http://localhost:5173
```

### 使用已构建的静态文件
```bash

# 或使用任意静态服务器
```

## 🔐 加密功能

本工具提供可选的 OpenPGP 加密功能，以增强助记词分片的安全性：

### 加密选项

- **对称加密**：使用 AES-256 算法和基于密码的加密
- **GPG 兼容性**：加密输出与标准 GPG 工具兼容
- **密码强度验证**：内置密码强度评估
- **安全密码生成**：可生成密码学安全的密码

### 加密流程

1. **密码创建**：创建强密码或使用内置生成器
2. **分片加密**：每个分片使用 OpenPGP 单独加密
3. **安全存储**：加密后的分片可以安全地存储在不太安全的介质上
4. **解密恢复**：使用相同密码解密恢复原始分片

### 密码安全

- **强度校验**：弱密码会被拦截，建议使用 12 位以上、混合大小写字母、数字与特殊字符
- **强度级别**：弱、中、强指示器及改进建议
- **安全生成**：密码学安全的随机密码生成
- **密码不落盘**：密码仅用于当次加解密，不写入任何分片或本地存储

## 🎯 使用方法

### 基本使用（不加密）

1. 打开 [应用页面](./index.html)
2. 选择助记词数量（12 或 24 个单词）
3. 配置分片总数和恢复阈值
4. 输入助记词，系统会自动验证每个单词
5. 点击"生成分片"生成多个分片
6. 将分片分别保存在不同的安全位置
7. 需要恢复时，输入任意指定数量的分片即可

### 加密使用（推荐）

1. 打开 [应用页面](./index.html)
2. 选择助记词数量（12 或 24 个单词）
3. 配置分片总数和恢复阈值
4. 输入助记词，系统会自动验证每个单词
5. 启用加密选项并创建强密码
6. 点击"生成并加密分片"创建加密分片
7. 将加密分片和密码分别保存在不同的安全位置
8. 需要恢复时，输入加密分片和密码进行解密恢复

### 文件上传恢复

1. 打开 [应用页面](./index.html)
2. 导航到"恢复助记词"部分
3. 选择"上传"标签
4. 上传您的分片文件（.txt 或 .gpg 格式）
5. 如果您有加密文件（.gpg），在提示时输入解密密码
6. 点击"恢复助记词"恢复您的原始助记词
7. 恢复的助记词将以清晰的单词分隔显示

### 混合恢复方法

- **粘贴方法**：直接将分片内容粘贴到输入字段中
- **上传方法**：上传分片文件进行批量处理
- **跳过解密**：当上传混合文件时，可以跳过未加密文件的解密

### 恢复演练（定期校验，推荐）

1. 生成分片时，记下页面显示的「助记词指纹」（8 位十六进制），抄写到保管卡上，与分片分开存放
2. 定期（建议每 6~12 个月）打开工具，切到「恢复助记词」，勾选「演练模式」
3. 输入预期指纹；留空则只验证分片可完整恢复（不比对身份），并显示本次恢复结果的指纹——旧版分片可借此建立指纹，抄写后下次演练即可比对
4. 粘贴或上传分片，点击「恢复助记词」
5. 看到「演练通过 · 指纹一致」即备份有效——全程未显示助记词明文，无暴露风险
6. 若提示某张分片「校验码不匹配」，重新核对该分片的抄录即可；富余分片足够时工具会自动跳过坏片完成演练
7. 演练完成后点击结果卡上的「擦除」，再执行一次全局「擦除所有数据」

### 地址观察（观察钱包导入）

1. 打开应用，切换到「观察地址」模式
2. 输入助记词（选择地址类型：Native SegWit 为 BlueWallet 默认，其余按钱包实际路径选择）
3. 若钱包设置了第 25 词，展开「passphrase（可选）」填写；未设置则留空
4. 点击「派生地址」获得收款地址列表（首尾 8 位高亮，方便比对）
5. 展开「观察钱包导出」卡片，点击「显示」核对 zpub，再用「二维码」让手机 BlueWallet 扫码：
   BlueWallet →「+」→ 导入钱包 → Watch-only → 扫描
6. 导入后核对：BlueWallet 首个收款地址应与本工具 0/0 行一致（比对首尾 8 位）
7. 用完点击「擦除所有数据」清空本页

**注意**：观察钱包只能查看余额与收款，不能花钱；转账签名始终留在冷钱包侧。本工具不显示私钥、不联网查询余额。

## 📱 安全建议

1. **离线环境使用** - 建议在断网环境中使用此工具
2. **分散存储** - 将分片保存在不同的物理位置
3. **安全介质** - 使用加密的 USB 驱动器或纸质备份
4. **定期验证** - 定期测试分片的恢复功能
5. **分片保护** - 不要将分片分享给不信任的人
6. **密码管理** - 将加密密码与加密分片分开存储
7. **强密码** - 使用内置密码生成器或创建高熵密码
8. **密码分离** - 将密码存储在与加密分片不同的位置
9. **记忆关键密码** - 考虑记忆加密密码以获得终极安全性
10. **密码备份** - 使用不同方法为加密密码创建安全备份
11. **建议开启加密分片** - 未加密（明文）分片在低于阈值数量时可能泄露助记词的结构信息（词数、编码特征）；开启 OpenPGP 加密后分片内容为均匀随机密文，可消除此风险，且密码层可随时用标准 GPG 工具（`gpg --decrypt`）解密
12. **离线保存一份工具** - `dist/mnemonic-shards-offline.html` 为单文件离线版，断网双击即可运行恢复，建议与分片一起归档，确保不依赖任何在线服务
13. **zpub 与二维码旁窥防护** - 观察模式的 zpub 默认模糊显示，点按「显示」后 60 秒自动重新遮蔽；二维码弹层关闭后立即回遮蔽。zpub 泄露只暴露余额隐私、不能转走资金，但仍请勿在不受信任的环境展示
14. **粘贴地址后核对首尾 8 位** - 向派生地址转账时，粘贴后请核对收币方显示地址的首尾 8 位与工具一致，防范剪贴板劫持类恶意软件替换地址
15. **抄写助记词指纹并分开保管** - 生成分片时页面会显示 8 位「助记词指纹」，将其抄写到保管卡上并与分片分开存放；日后演练恢复时输入指纹，可在完全不显示助记词的情况下确认备份有效。指纹仅 32 位、不写入分片，泄露它无法推出助记词
16. **定期演练** - 建议每 6~12 个月用「演练模式」做一次零暴露恢复演练，确认分片仍然有效；带校验码的分片在抄录损坏时会被工具点名定位，避免"知道坏了却不知道坏在哪张"

## 📄 分片格式规范（逃生舱文档）

即使不使用本工具，你也可以依据以下公开格式自行实现恢复，分片不会深度绑定本项目：

- 每份分片是一个 Base64 字符串，解码后为 JSON：`{"index": <分片序号>, "threshold": <恢复阈值>, "total": <总分片数>, "data": "<Base64(秘密分片字节)>", "checksum": "<8位分片校验码，v1.2+ 可选>"}`
- `checksum`（可选，v1.2+）：`data` 字段 Base64 解码后的字节取 SHA-256 前 5 字节，用 Crockford Base32（字母表 `0123456789ABCDEFGHJKMNPQRSTVWXYZ`，排除 I/L/O/U）编码为 8 个字符。该字段仅供人工核对与恢复时定位损坏分片，**恢复算法本身不使用它**——缺少该字段的旧格式分片（以及任何忽略该字段的第三方实现）均可正常恢复
- 助记词指纹（页面展示与演练比对用，**不写入分片**）：SHA-256(归一化助记词) 前 4 字节的十六进制大写。归一化 = trim → 按空白拆分 → 单空格连接 → 转小写。示例：官方测试向量 `abandon … about` 的指纹为 `C557EEC8`
- 恢复步骤：取任意 `threshold` 份分片 → 解码 JSON → Base64 解码 `data` 字段 → 使用 GF(2^8) 上的 Shamir 秘密分享（如 [shamir-secret-sharing](https://www.npmjs.com/package/shamir-secret-sharing) 库，经独立审计）合并 → 得到 UTF-8 编码的助记词 → 按 BIP39 标准校验
- 开启加密时分片文件为标准 OpenPGP 格式（`.gpg`），先用 `gpg --decrypt` 解密得到上述 Base64 字符串，再按上述步骤恢复
- 可运行 `npm run verify` 查看一个不依赖本项目代码的独立恢复演示
